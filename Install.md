### Installation Guide
---
### All Terminal/PowerShell
---
### Make Venv - REMEMBER PYTHON 3.13.9
```bash
py -3.13 -m venv .venv
```
### Activate Environment
```bash
./.venv/Scripts/activate
```

### Install pygame - MAKE SURE YOU HAVE PYTHON 3.13.9
```bash
pip install pygame

or

pip install -r requirements.txt
```

### Run Main
```bash
python main.py
```
